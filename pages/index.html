quickwin 示例集合

基于 quickwin 的桌面实用工具， TypeScript 写、一个 .exe 交。

→

deskmon（桌面监控悬浮窗）

贴在桌面上的小挂件：实时显示网速、内存和 CPU 使用率，深浅背景可切、记住拖动位置。

1.2 MB · 单文件 · 免安装 · Windows XP+ (32 位) · 已在 XP / Windows 7 / Windows 11 验证

→

lanfile（局域网文件互传）

电脑开服务、手机浏览器扫码上传：给 XP / Win7 老机器装一个「扫码收发」，不依赖网盘、不出外网。

1.3 MB · 单文件 · 免安装 · Windows XP+ (32 / 64 位) · 已在 XP / Windows 7 验证

→

uback（U 盘自动备份）

插上 U 盘就自动把文件增量备份到电脑，托盘常驻、开机自启；只认硬件序列号，只增不删。

1.3 MB · 单文件 · 免安装 · Windows XP+ (32 / 64 位) · 已在 XP / Windows 7 验证

每次 push 由 npm run build（tsc + esbuild + brotli embed）自动构建 — 源码在 GitHub。
