deskmon（桌面监控悬浮窗）

一条贴在桌面上的小挂件：实时显示网速、内存和 CPU 使用率，每秒刷新。

Windows 11
Windows 7
Windows XP

可随手拖到任意位置，位置和背景深浅会被记住，重启自动恢复。 托盘右键菜单：置顶、大小档（100%–200%）、浅色 / 深色背景、开机自启动、退出。

1.2 MB · 单文件 · 免安装 · Windows XP+ (32 位) · 已在 XP / Windows 7 / Windows 11 验证
